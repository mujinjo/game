# Game Brief: 싸발적인 투타대결

**One-sentence pitch:** 포수 뒤 시점에서 날아오는 공의 높이를 읽고, 타이밍에 맞춰 어퍼·레벨·다운 중 하나로 스와이프해 받아치고, 공수를 바꿔 CPU 타자를 잡아내는 1이닝 투타 대결.

## Core loop
- 투수가 구종과 코스를 정해 던진다 (CPU 또는 플레이어)
- 타자가 공 높이를 읽고, 타이밍에 맞춰 스와이프로 스윙한다 (위 = 어퍼, 옆 = 레벨, 아래 = 다운)
- 결과(헛스윙 / 파울 / 아웃 / 안타 / 홈런)가 카운트, 주자, 점수에 반영된다
- 3아웃이 되면 공수가 바뀌고, 다음 타석으로 반복된다

## Player goal & fail state — what "working" looks like
- 목표: 1이닝(초·말)이 끝났을 때 CPU보다 점수가 높으면 승리
- 실패: 점수가 낮으면 패배, 같으면 무승부. 한 판은 3~5분이다.

## MVP — what must exist to be the game
1. 투구 궤적과 스트라이크존 판정 (볼 / 스트라이크 / 볼넷 / 삼진)
2. 스와이프 스윙 타격. 스와이프를 시작한 순간이 타이밍이고 방향이 스윙 종류(어퍼 / 레벨 / 다운)다. 타이밍 정확도와, 공 높이와 스윙 종류의 궁합으로 타구 결과가 정해진다.
3. 플레이어 투구: 구종 3개(직구 / 커브 / 체인지업)를 고르고 코스를 클릭한다.
4. 사람 / CPU 조작기 구조와 CPU 투수·타자 AI
5. 이닝 진행: 아웃, 주자 진루, 점수, 공수 교대
6. HUD와 시작 / 결과 화면 (모드 선택은 일단 vs CPU만)
7. 밸런스 수치(공 속도, 판정 범위, AI 난이도)를 외부 데이터로 분리

## Out of scope — not building this
- 2인 대전 (조작기 구조만 준비하고 다음 단계에서 붙인다)
- 3D (2D가 재미있다고 확인된 뒤에 검토)
- 수비와 주루 조작 (타구 결과는 확률로 판정)
- 선수 능력치, 팀 구성, 시즌 모드, 저장, 온라인

## Build order
1. 타격: 공 날아오기, 스와이프 스윙, 타이밍·궁합 판정. 재미를 가장 먼저 증명해야 하는 부분이다.
2. 볼카운트와 타구 결과 판정
3. CPU 투수 AI (여기까지 오면 타자 모드만으로 플레이할 수 있다)
4. 플레이어 투구와 CPU 타자 AI
5. 이닝, 점수, 공수 교대
6. HUD, 시작 / 결과 화면, 밸런스 데이터 분리

---
**Who it's for / what they feel:** 짧게 한 판 하고 싶은 야구 팬. "딱!" 맞았을 때의 손맛과 한 구 한 구의 긴장감을 느낀다.

**Art & audio direction:** 깔끔한 플랫 2D 벡터(브라우저 Canvas)와 포수 뒤 시점. 타격음과 관중 함성을 강조한다.

**Reference game:** 모바일 원터치 야구 게임의 타이밍 스윙에 스윙 종류(어퍼 / 레벨 / 다운) 선택을 더한 형태. 수비, 주루, 선수 육성은 제외한다.
